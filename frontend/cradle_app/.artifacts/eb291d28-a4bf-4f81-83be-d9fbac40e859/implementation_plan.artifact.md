# Implementation Plan - Native Mobile System Notifications Integration

This plan integrates real mobile system notifications (`flutter_local_notifications`) into the existing in-app notification and reminder flow without altering any existing UI, screens, navigation, or business logic.

## User Review Required

> [!IMPORTANT]
> - **New Dependency**: We will add `flutter_local_notifications` to `pubspec.yaml` to handle local and scheduled device notifications on Android and iOS.
> - **Zero UI Redesign**: Existing screens and navigation remain 100% untouched. System notifications will be triggered alongside existing in-app notifications when fetched/generated by the app.
> - **Permissions**: Proper Android 13+ (`POST_NOTIFICATIONS`) and iOS permission requests will be added during initialization.

## Proposed Changes

### 1. Dependencies & Configuration

#### [MODIFY] [pubspec.yaml](file:///D:/code/Cradle/frontend/cradle_app/pubspec.yaml)
- Add `flutter_local_notifications: ^17.2.1` (or latest stable compatible version).
- Configure Android permissions in `AndroidManifest.xml` (e.g. `POST_NOTIFICATIONS`, `VIBRATE`, `RECEIVE_BOOT_COMPLETED`).

### 2. Notification Service

#### [NEW] [LocalNotificationService](file:///D:/code/Cradle/frontend/cradle_app/lib/core/services/local_notification_service.dart)
- Initialize `FlutterLocalNotificationsPlugin` with Android and iOS settings.
- Create notification channels.
- Request runtime permissions (`POST_NOTIFICATIONS`).
- Provide methods to show instant local notifications (`showNotification`) and handle notification taps.

### 3. Integrating with Existing Notification Flow

#### [MODIFY] [NotificationProvider](file:///D:/code/Cradle/frontend/cradle_app/lib/providers/notification_provider.dart)
- When `fetchNotifications()` fetches new/unread notifications from the backend, compare against previously seen IDs and trigger a system notification (`LocalNotificationService.showNotification`) for any new unread notification.

## Verification Plan

### Manual Verification
- Start the backend and frontend.
- Trigger/fetch notifications in the app and verify that a real system notification appears in the Android/iOS status bar and notification panel.
- Tap the system notification and verify it opens the app's notifications screen.
- Verify notification permissions are requested correctly on Android 13+.
